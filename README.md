## Overview

This repository/collection documents a one-month, project-based Web Development internship at **Thiranex**. The internship progressed from semantic, accessible front-end foundations through client-side JavaScript logic and API integration, culminating in a deployed full-stack capstone.

Four applications were built and delivered:

1. **Personal Portfolio Website** — HTML5 Semantic Structure & Accessibility, Advanced CSS3 & Responsive Architecture
2. **To-Do List** — JavaScript Logic & State Management
3. **Weather Dashboard** — Asynchronous JavaScript & RESTful APIs
4. **ShopSphere** — Full-Stack Deployment & Project Architecture (Capstone)

---

## Projects

### 1. Personal Portfolio Website

Multi-page personal portfolio built to modern semantic HTML5 and WCAG accessibility standards, then made fully responsive with advanced CSS3.

- Semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- ARIA labels/roles and an accessible, tab-navigable contact form
- SEO-optimized meta tags
- CSS Grid + Flexbox layouts, mobile-first media queries
- Custom-property-driven light/dark theme

**Live:** https://vedanshportfolioo.netlify.app/

---

### 2. To-Do List

Interactive, client-side task manager focused on DOM manipulation, event handling, and local data persistence.

- Full CRUD (Create, Read, Update, Delete)
- Filtering: All / Active / Completed
- Persistent storage via `localStorage` + JSON serialization
- Dynamically created DOM elements with delegated event listeners
- Live count of remaining tasks

**Project Files:** https://drive.google.com/drive/folders/1QCj-h0WEtM6kcHb_l-zyy_e-Dwul9tX_?usp=drive_link

---

### 3. Weather Dashboard

Real-time weather lookup dashboard that fetches and renders live JSON data from a public REST API.

- Live data via Fetch API + `async/await`
- City search with dynamic result rendering
- Temperature, humidity, wind speed, and pressure metrics
- Error handling for invalid city names and network failures
- Fully responsive layout

**Project Files:** https://drive.google.com/drive/folders/151uQUSzZK9sd3iyyM3cY8oNcYlzx0E3b?usp=drive_link

---

### 4. ShopSphere (Capstone)

Production-style e-commerce product catalog combining all prior learning into a single deployed application.

- Modular, component-based React architecture
- Client-side routing (catalog, product details, cart, account pages)
- Product search, category filters, cart & wishlist (`localStorage`)
- REST API-driven product data with loading/error states
- Optimized production build, deployed live

**Live:** https://shopsphere-capstone.lovable.app/

## Development Methodology

1. **Requirement Analysis** — review task requirements & expected outcomes
2. **Planning** — map UI, state, functions, and data flow
3. **Core Implementation** — build required functionality first
4. **Validation & Error Handling** — cover edge cases and failure states
